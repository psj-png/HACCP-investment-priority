# 식품안전 리스크 및 경제적 영향을 고려한 HACCP 투자 우선순위 평가

> 2026 한국식품안전관리인증원 공공데이터 분석·활용 경진대회 출품작

## 문제 정의

HACCP 인증 확대를 위한 정부 예산은 한정되어 있다. 현행 방식은 업종·지역 단위로 균등 배분하지만, 식품군마다 안전 위험도와 경제적 영향이 다르기 때문에 동일한 투자가 동일한 효과를 보장하지 않는다.

본 프로젝트는 금융의 자본배분(Capital Allocation) 개념을 적용하여, **"한정된 HACCP 투자 자원을 어떤 식품군에 먼저 배분해야 하는가"**를 데이터 기반으로 제안한다.

## 분석 프레임워크

식품군별 투자 우선순위 스코어를 4개 변수의 가중합으로 산출한다.

```
Priority Score(i) = w1·Risk(i) + w2·Scale(i) + w3·Vulnerability(i) + w4·Impact(i)
```

| 변수 | 정의 | 조작적 정의 |
|---|---|---|
| **Risk** | 해당 식품군의 안전 위험도 | 위반 건수, 부적합률, 위해요소 유형 |
| **Scale** | 해당 식품군의 경제적 규모 | 생산액, 생산량, 출하액 |
| **Vulnerability** | HACCP 인증 취약도 | 1 − (HACCP 인증 업체 수 / 전체 업체 수) |
| **Impact** | 사고 발생 시 피해 규모 | 회수·판매중지 건수, 식중독 환자 수 |

가중치는 동일 가중 후 민감도 분석(가중치 변화에 따른 순위 변동 확인)으로 검증한다.

## 데이터 조인 설계

CSV 파일들은 **품목유형명**으로 직접 조인된다 (표기 차이는 치환으로 해결).

HACCP 인증업체 API는 개별 품목코드(`businessitem`)로 기록되어 있으므로, 품목코드 API의 상위 카테고리 코드(`pcd`)를 통해 식약처 통계의 품목유형과 매핑한다.

```
HACCP 인증업체.businessitem (예: C10100016)
  → 품목코드.pcd (예: C101)
    → 품목유형 (예: 음료류)
      → CSV 파일 조인 키
```

## 분석 파이프라인

```
[1] 데이터 수집
    ├── 식약처 CSV 8개 다운로드 ✅
    ├── HACCP 인증업체 API 전체 수집 (41,083건)
    └── 품목코드 API 매핑 테이블 구축

[2] 전처리 및 조인
    ├── CSV 파싱 + 품목유형명 통일
    ├── API 데이터: businessitem → pcd → 품목유형 매핑
    └── 식품군 기준 단일 테이블 통합

[3] 변수 산출 및 스코어링
    ├── Risk / Scale / Vulnerability / Impact 정규화
    ├── Priority Score 산출
    └── 민감도 분석 (가중치 변화 시 순위 안정성)

[4] 시각화 및 보고서
    ├── 식품군별 스코어 순위
    ├── 변수별 비교 차트
    └── 정책 제언: 우선 투자 대상 식품군 도출
```
