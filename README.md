# 식품안전 리스크 및 경제적 영향을 고려한 HACCP 투자 우선순위 평가

> 2026 한국식품안전관리인증원 공공데이터 분석·활용 경진대회 출품작 (데이터 분석 부문)

## 문제 정의

HACCP 인증 확대를 위한 정부 예산은 한정되어 있다. 정부는 현재 **업체 규모(매출 5억 미만·종업원 21인 미만)**를 기준으로 시설개선자금(연 39억, 개보수 비용 50% 국고 지원)을 **신청 순서(선착순)**로 배분한다. 그러나 이 방식에는 **"어느 식품군이 더 시급한가"**라는 축이 없다. 이미 인증율이 포화된 식품군과 위험·취약한 식품군이 동일하게 취급된다.

본 프로젝트는 금융의 자본배분(Capital Allocation) 개념을 적용하여, **"한정된 HACCP 투자 자원을 어떤 식품군에 먼저 배분해야 하는가"**를 데이터로 산출한다. 정부의 기존 기준(업체 규모)을 부정하지 않고, 여기에 **식품군별 우선순위**라는 축을 더해 예산 배분을 정교화하는 의사결정 보조지표를 제안한다.

## 분석 프레임워크

식품군별 투자 우선순위 점수(HIP)를 4개 변수의 가중합으로 산출한다.

```
HIP (HACCP Investment Priority)
  = (Risk + Scale + Vulnerability + Impact) / 4   # 동일가중
```

| 변수 | 의미 | 조작적 정의 | 데이터 출처 |
|---|---|---|---|
| **Risk** | 안전 위험도 | 부적합률 (베타-이항 축소 보정) | 식약처 1-4-3 수거검사 |
| **Scale** | 경제적 규모 | 생산액 (log10 변환) | 식약처 1-2-1-2 생산실적 |
| **Vulnerability** | HACCP 취약도 | 1 − (HACCP 인증 업체 수 / 전체 업체 수) | 인증원 API + 식약처 1-1-1-2 |
| **Impact** | 사고 발생 | 등급별 회수 건수 (2024년 이후, 동일 업체·일자·사유 중복 제거) | 식약처 I0490 회수·판매중지 |

모든 변수는 0~1로 정규화(변수 특성에 맞춰 min-max/log 차등 적용) 후 합산한다. 가중치의 자의성을 배제하기 위해 **SMAA(Stochastic Multicriteria Acceptability Analysis)**를 적용: 변수 가중치는 완전 무작위(Dirichlet), 회수등급 가중치는 순서 제약(1≥2≥3, 식약처 등급 정의)만 두고 몬테카를로 10,000회 추출해 순위 분포를 산출한다. 핵심 지표는 top5 유지율(순위 수용성 지수), 대표값은 중앙 순위, 동점 정리는 평균 순위다.

**검증 3종**: ① 가중치 1만 회 무작위 ② 적용공백 포함/제외 비교 ③ Impact 기간·중복 처리 3버전 비교. 세 검증 모두에서 상위 5개 식품군이 동일하게 나타났다.

**2×2 분류**: 순위(어디부터)와 별개로 검토 방향(무엇을)을 구분하기 위해, 적용공백(가로)×부적합률(세로)을 각 축 중앙값 기준 4분면으로 나눈다. 원 크기는 회수 건수이며 칸 결정에는 사용하지 않는다.

| 분류 | 조건 | 검토 방향 |
|---|---|---|
| ① 우선 지원·관리 검토 | 인증 낮음 + 부적합 높음 | HACCP 기술지원·교육·도입 지원 우선 검토 |
| ② 현황 모니터링 | 인증 낮음 + 부적합 낮음 | 낮은 인증 수준만으로 관리 부실을 판단하지 않고 현황 지속 모니터링 |
| ③ HACCP 운영·관리 실효성 추가 점검 | 인증 높음 + 부적합 높음 | 적용 확대만으로 충분한지 검토하고, 사후관리·현장 운영·비인증 영역 포함 추가 점검 |
| ④ 현 수준 유지·지속 모니터링 | 인증 높음 + 부적합 낮음 | 현 관리 수준 유지하며 지속 모니터링 |

> 본 분류는 식품군 단위의 HACCP 인증 수준과 검사상 부적합 발생 수준을 활용한 1차 선별 결과이며, HACCP 운영 적정성 또는 개별 업체의 안전관리 수준을 직접 평가하는 것은 아니다. 순위·예산 배분에는 사용하지 않는다.

**적용구분** (「식품위생법 시행규칙」 제62조 제1항, 해석 전용): 대부분 의무 5개 / 일부 의무 5개 / 100억 기준 적용 10개. 마지막 분류는 "품목별 의무대상은 아니나, 전년도 총매출액 100억 원 이상인 식품제조·가공업 영업소에서 제조·가공하는 경우 HACCP 적용 대상이 되는 식품군"을 뜻하며 점수·순위·2×2 어디에도 사용하지 않는다.

## 주요 결과

**최우선 투자 대상 (SMAA top5 유지율):**
- 음료류 99.1%, 기타식품류 94.9%, 조미식품 89.7%, 농산가공식품류 77.4%, 빙과류 53.3%

**검증 3종 모두 통과:**
- ① 가중치 1만 회 무작위 ② 적용공백 포함/제외 ③ Impact 기간·중복 처리 3버전 — 세 검증 모두에서 상위 5개 식품군 동일

**2×2 분류 (각 5개, 기준선 = 각 축 중앙값):**

| 분류 | 식품군 |
|---|---|
| Ⅰ 우선 지원·관리 검토 | 음료류, 기타식품류, 절임류 또는 조림류, 두부류 또는 묵류, 벌꿀 및 화분가공품류 |
| Ⅱ 현황 모니터링 | 조미식품, 농산가공식품류, 장류, 당류, 동물성가공식품류 |
| Ⅲ 운영·관리 실효성 추가 점검 | 빙과류, 즉석식품류, 식용유지류, 과자류·빵류·떡류, 특수영양식품 |
| Ⅳ 현 수준 유지·지속 모니터링 | 수산가공식품류, 코코아·초콜릿류, 면류, 잼류, 특수의료용도식품 |

**적용공백 의존도 검증:**
- 적용공백 제외 시 순위가 하락하는 식품군 5개(장류·벌꿀·당류·동물성가공·잼류), 상승하는 식품군 4개(과자류·빙과류·특수영양·면류). 인증률이 순위를 양방향으로 왜곡할 수 있음을 확인했으며, 나머지 11개는 적용공백과 무관하게 순위가 유지된다.

## 분석 대상

식품제조·가공업 기준 **20개 품목유형**. 축산물 3개(「축산물 위생관리법」 소관으로 의무 적용의 법적 기반 상이), 주류(국세청 소관), 식품첨가물(별도 업종)은 제외. 근거는 [`docs/data-mapping.md`](docs/data-mapping.md) 참조.

## 데이터 출처

### 한국식품안전관리인증원 (필수)

| 데이터 | 용도 |
|---|---|
| HACCP 인증업체정보 API (`CertCompanyListService2`) | 품목유형별 인증 업체 수 (적용공백 분자) |
| 품목코드정보 API (`PrdLstListService`) | `businessitem` → `pcd` 품목유형 매핑 |

### 식품의약품안전처 (보조)

| 데이터 | 용도 |
|---|---|
| 1-1-1-2 식품제조가공업체 현황 | Vulnerability 분모 (전체 업체 수) |
| 1-2-1-2 생산량·생산액 | Scale |
| 1-4-3 수거·검사건수 | Risk (부적합률) |
| I0490 회수·판매중지 정보 | Impact |

### 확인했으나 미사용 (데이터 한계)

| 데이터 | 미사용 사유 |
|---|---|
| 위해요소·CCP 중요관리점 정보 | 업종 단위 제공, 품목유형 매핑 불가 (식품 데이터 23행뿐, 대부분 축산) |
| HACCP 심사수수료 API (`CostListService`) | 업종 단위 제공, 품목유형별 미구분 |
| HACCP 평가표 API (`ScoreListService`) | 평가 기준 문항이라 품목유형별 관리복잡성 산출 불가 |

→ 인증원의 위해요소·CCP·수수료 데이터가 모두 **업종 단위**로만 제공되어, 식약처 통계의 **품목유형 단위**와 매핑되지 않는다는 구조적 한계 확인. 이는 향후 공공데이터 개선 시 품목유형 단위 제공 필요성을 시사한다 (정책 제언에 포함).

## 주요 한계

1. Scale–Impact 순위상관 0.58(설명력 18%) — 회수 건수에 규모 효과가 부분 반영
2. 구조 지표는 2024년, 회수는 2024~2026년 — 기준 시점이 다르며, 구조 지속을 전제한 예측 모형이 아니라 시점이 명시된 복수 지표의 종합 지수
3. 2026년은 9월까지의 부분 연도
4. I0490에 회수 촉발 경로(정부 수거·검사/자가품질검사/민원) 항목이 없어 검사 정책 관련 결론은 도출 불가
5. 적용공백 분모에 의무·비의무 업체가 혼재(음료류는 다류·커피류, 빙과류는 축산물 소관 아이스크림류 포함 가능)
6. 2×2 ③칸은 인증업체/미인증업체 구분 불가 — "인증업체 관리 부실"로 해석 불가
7. 절임류 또는 조림류는 중복률 55%로 Impact 처리 방식에 민감
8. 회수는 세부 품목까지 제공되나 부적합률·생산액·인증률은 품목유형 단위 — 세부 품목 수준 위험도 비교 불가
9. 2025년 식약처 통계가 발표되었으나 분석 착수 시점 기준 2024년 자료 사용
