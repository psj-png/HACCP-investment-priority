# 식품안전 리스크 및 경제적 영향을 고려한 HACCP 투자 우선순위 평가

> 2026 한국식품안전관리인증원 공공데이터 분석·활용 경진대회 출품작 (데이터 분석 부문)

## 문제 정의

HACCP 인증 확대를 위한 정부 예산은 한정되어 있다. 정부는 현재 **업체 규모(매출 5억 미만·종업원 21인 미만)**를 기준으로 시설개선자금(연 39억, 개보수 비용 50% 국고 지원)을 **신청 순서(선착순)**로 배분한다. 그러나 이 방식에는 **"어느 식품군이 더 시급한가"**라는 축이 없다. 이미 인증율이 포화된 식품군과 위험·취약한 식품군이 동일하게 취급된다.

본 프로젝트는 금융의 자본배분(Capital Allocation) 개념을 적용하여, **"한정된 HACCP 투자 자원을 어떤 식품군에 먼저 배분해야 하는가"**를 데이터로 산출한다. 정부의 기존 기준(업체 규모)을 부정하지 않고, 여기에 **식품군별 우선순위**라는 축을 더해 예산 배분을 정교화하는 의사결정 보조지표를 제안한다.

## 분석 프레임워크

식품군별 투자 우선순위 점수(HIP)를 4개 변수의 가중합으로 산출한다.

```
HIP (HACCP Investment Priority)
  = (Risk + Scale + Vulnerability + Impact) / 4   # 동일가중
```

| 변수 | 의미 | 조작적 정의 | 데이터 출처 |
|---|---|---|---|
| **Risk** | 안전 위험도 | 부적합률 (베타-이항 축소 보정) | 식약처 1-4-3 수거검사 |
| **Scale** | 경제적 규모 | 생산액 (log10 변환) | 식약처 1-2-1-2 생산실적 |
| **Vulnerability** | HACCP 취약도 | 1 − (HACCP 인증 업체 수 / 전체 업체 수) | 인증원 API + 식약처 1-1-1-2 |
| **Impact** | 사고 피해 규모 | 등급별 회수 건수 (가중치는 몬테카를로) | 식약처 I0490 회수·판매중지 |

모든 변수는 0~1로 정규화(변수 특성에 맞춰 min-max/log 차등 적용) 후 합산한다. 가중치의 자의성을 배제하기 위해 **몬테카를로 민감도 분석**을 적용: 변수 가중치(R/S/V/I)는 완전 무작위, 회수등급 가중치(1/2/3)는 순서 제약(1≥2≥3, 식약처 등급 정의)만 두고 10,000회 추출해 순위 분포를 산출한다. 특정 가중치 값을 지정하지 않으므로 "왜 이 값인가"라는 반박이 성립하지 않는다.

## 주요 결과

**최우선 투자 대상 (몬테카를로 top5 유지율):**
- 기타식품류 95.6%, 음료류 93.4%, 조미식품 70.4%, 빙과류 65.8%, 식육가공품 57.1% — 가중치와 무관하게 상위권 유지 (강건)

**관점 의존적:**
- 장류(top5 23.6%): 취약도 강조 시 급상승 / 유가공품류(30.6%): 부적합률 높으나 회수 0

**관점별 판단 필요:**
- 유가공품류: 부적합률 높으나 실제 회수 0 → 예방적 투자 대상
- 장류: 인증율 8.1%로 취약도 최고 → 형평성 관점에서 우선순위 상승

**후순위 (이미 포화):**
- 특수의료용도식품·특수영양식품·코코아류 (인증율 높고 규모 작음)

## 분석 대상

식품제조·가공업 기준 **23개 품목유형**. 축산물(별도 부처 소관), 주류(국세청 소관), 식품첨가물(별도 업종)은 데이터 정합성을 위해 제외. 근거는 [`docs/data-mapping.md`](docs/data-mapping.md) 참조.

## 데이터 출처

### 한국식품안전관리인증원 (필수)

| 데이터 | 용도 |
|---|---|
| HACCP 인증업체정보 API (`CertCompanyListService2`) | 품목유형별 인증 업체 수 (Vulnerability 분자) |
| 품목코드정보 API (`PrdLstListService`) | `businessitem` → `pcd` 품목유형 매핑 |

### 식품의약품안전처 (보조)

| 데이터 | 용도 |
|---|---|
| 1-1-1-2 식품제조가공업체 현황 | Vulnerability 분모 (전체 업체 수) |
| 1-2-1-2 생산량·생산액 | Scale |
| 1-4-3 수거·검사건수 | Risk (부적합률) |
| I0490 회수·판매중지 정보 | Impact |

### 확인했으나 미사용 (데이터 한계)

| 데이터 | 미사용 사유 |
|---|---|
| 위해요소·CCP 중요관리점 정보 | 업종 단위 제공, 품목유형 매핑 불가 (식품 데이터 23행뿐, 대부분 축산) |
| HACCP 심사수수료 API (`CostListService`) | 업종 단위 제공, 품목유형별 미구분 |
| HACCP 평가표 API (`ScoreListService`) | 평가 기준 문항이라 품목유형별 관리복잡성 산출 불가 |

→ 인증원의 위해요소·CCP·수수료 데이터가 모두 **업종 단위**로만 제공되어, 식약처 통계의 **품목유형 단위**와 매핑되지 않는다는 구조적 한계 확인. 이는 향후 공공데이터 개선 시 품목유형 단위 제공 필요성을 시사한다 (정책 제언에 포함).

## 파이프라인

```
[1단계] 데이터 수집 ✅
    ├── HACCP 인증업체 API 수집 (41,091건, XML/JSON 자동분기 + 재시도)
    ├── 품목코드 API → pcd 매핑
    └── 식품제조가공업 필터 + 업체 중복제거 → 23개 품목유형

[2단계] 조인 및 정합성 확보 ✅
    ├── 품목유형명 정규화 (영문/주석 제거, 동의어 통일)
    ├── 세부행 합산 (분할된 품목유형 재집계)
    ├── 분자·분모 범위 통일 (식품·제조가공업·업체단위)
    └── data/processed/merged.csv (23개 품목유형 × 지표)

[3단계] 스코어링 ✅
    ├── 회수 데이터 → 품목유형별 등급별 건수 (map_recall.py)
    ├── 몬테카를로 민감도 — 가중치 무작위 1만 회 → 순위 분포 (montecarlo.py)
    └── 4변수 HIP + 베타-이항 축소, 몬테카를로 중앙순위 정본 (score.py)

[4단계] 시각화 (visualize.py) ✅
    ├── fig0 EDA (변수 분포 + 변환 근거)
    ├── fig1~3 순위·구성·민감도 (결론·근거·신뢰도)
    ├── fig4 위험-규모 매트릭스 (0.5/중앙값 병치)
    ├── fig5 예산 배분 시뮬레이션
    └── fig6 베타-이항 보정 효과

[5단계] 정책 제언 및 발표자료 ⏳
```

## 실행 방법

```bash
pip install requests

# 1단계: API 수집 + 집계
python src/collect_haccp_api.py

# 2단계: CSV 조인
python src/merge_csv.py

# 3단계: 회수 등급별 건수 → 몬테카를로 → 스코어링
python src/map_recall.py
python src/montecarlo.py
python src/score.py

# 4단계: 시각화 (코랩에서 한글 폰트 설정 후 실행)
python src/visualize.py
```

식약처 CSV(1-1-1-2 등)와 I0490.csv는 `data/raw/`에 미리 위치시켜야 한다.
