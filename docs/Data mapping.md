# 데이터 매핑 설계 기록

## 개요

식품군별 HACCP 투자 우선순위 스코어를 산출하려면, 서로 다른 기관·형태의 데이터를 **품목유형** 기준으로 조인해야 한다. 이 문서는 데이터 탐색 과정에서 발견한 문제와 해결 방법을 기록한다.

---

## 1. 데이터 분류

### 즉시 사용 가능 (식약처 CSV)

식약처 통계 사이트에서 다운로드한 집계 통계표. 행 = 품목유형, 열 = 수치.

| 파일 | 분류 기준 | 시간 범위 | 핵심 컬럼 |
|---|---|---|---|
| 1-1-1-1 | 업종별 | 2001-2024 | 전체 업체 수 |
| 1-1-1-2 | 품목유형별 × 시도별 | 2024 | 업체 수 |
| 1-2-1-1 | 대분류 4개 | 2014-2024 | 생산액, 출하액, 수출액 |
| 1-2-1-2 | 품목유형별 | 2024 | 생산능력, 생산량, 생산액 |
| 1-2-1-8 | 종업원규모별 | 2004-2024 | 업체 수, 매출액 |
| 1-3-1-1 | 품목유형별 | 2014-2024 | 감시건수, 위반유형별 건수 |
| 1-4-3 | 품목유형별 | 2024 | 검사, 적합, 부적합, 부적합률 |

### API 수집 필요 (HACCP 인증원)

| API | End Point | 건수 | 핵심 필드 |
|---|---|---|---|
| HACCP 인증업체정보 | `apis.data.go.kr/B553748/CertCompanyListService2` | 41,083건 | company, productGb, businessitem, businessitemNm |
| 품목코드정보 | `apis.data.go.kr/B553748/PrdLstListService` | 매핑 테이블 | cd, pcd, cdnmKr |

### 사용하지 않는 데이터

| 데이터 | 제외 사유 |
|---|---|
| 1-5-2 (HACCP 인증 품목별 CSV) | 자율적용 "기타 품목" 5,996건(54%)이 품목유형 미분류. API로 대체 |
| HACCP 표준기준서 (파일데이터) | 업종별 Word/PDF 매뉴얼. 정량 분석 불가 |
| 심사수수료 정보 | 스코어링 모델에 불필요 (비용 축은 분석 범위 밖) |
| 식품안전나라 별도 API | 식약처 CSV와 동일 원천 데이터. 중복 수집 불필요 |

## 2. 조인 키: 품목유형명

CSV 파일 간 조인 키는 "품목유형명"이지만, 표마다 표기가 다르다.

### 표기 차이 예시

| 1-2-1-2 (생산) | 1-3-1-1 (위반) | 1-4-3 (수거검사) | 1-1-1-2 (업체) |
|---|---|---|---|
| 과자류, 빵류 또는 떡류 | 과자류, 빵 또는 떡류 | 과자류, 빵류 또는 떡류 | 과자류, 빵류 또는 떡류 |
| 유가공품류 | 유함유가공품 | 유가공품류 | 유가공품 |
| 식육가공품 및 포장육 | 식육함류가공품 | 식육가공품 및 포장육 | 식육가공품 및 포장육 |
| 기타식품류 | 기타식품류1) | 기타식품류 | 기타식품류 1) |

### 해결 방법

문자열 치환으로 통일. "빵" → "빵류", 후행 주석("1)") 제거, 영문 제거 등 전처리 후 매칭.

## 3. 핵심 문제: HACCP 인증 데이터의 품목유형 매핑

### 문제

Vulnerability(취약도) 산출에는 "식품군별 HACCP 인증 업체 수"가 필요하다. 식약처 CSV(1-5-2)에서 이를 제공하지만, 분류 체계가 다른 표와 일치하지 않는다.

1-5-2는 의무적용 품목(배추김치, 어묵류 등 16개)을 세부 단위로 나열하고, 자율적용 품목은 "기타 품목 5,996건"으로 합산 → 전체의 54%가 품목유형 미분류.

```
CSV 표 (1-2-1-2 등):  "수산가공식품류" = 1행
1-5-2 HACCP 표:        "냉동수산식품" 1,077건
                       "어묵류" 105건
                       "어육소시지" 16건
                       → 합치면 수산가공식품류에 대응하지만,
                       나머지 15개 품목유형은 "기타"에 매몰
```

### 해결

HACCP 인증업체 API를 사용. 이 API는 업체 1건마다 개별 품목코드(`businessitem`)를 제공한다.

품목코드 API에서 각 코드의 상위 카테고리(`pcd`)를 조회하면, 식약처 CSV의 품목유형과 동일한 단위로 집계할 수 있다.

---

## 4. API 필드 구조

### HACCP 인증업체 API 응답 (1건)

```json
{
  "company": "미산식품",
  "productGb": "식품",
  "businessitem": "C10100016",
  "businessitemNm": "혼합음료",
  "businesstypeNm": "식품제조가공업",
  "companykindNm": "제조,가공",
  "area1": "경기도",
  "area2": "부천시",
  "appointno": "2021-3-0572",
  "issuedate": "2021-05-11",
  "issueenddate": "2027-05-10"
}
```

- `productGb`: "식품" 또는 "축산물" → 식품만 필터링
- `businessitem`: 개별 품목코드 → 품목코드 API와 조인 키
- 일일 트래픽 제한: 10,000건 → 41,083건 수집에 최소 5회 호출 필요 (페이징)

### 품목코드 API 응답 (1건)

```json
{
  "cd": "C10100016",
  "pcd": "C101",
  "cdnmKr": "혼합음료",
  "useyn": "Y"
}
```

- `cd`: 개별 품목코드 = 인증업체 API의 `businessitem`과 매칭
- `pcd`: 상위 카테고리 코드 → 품목유형으로 변환
- `useyn`: "Y"만 현행 사용 중인 코드

## 6. 최종 조인 플로우

```
[식약처 CSV]                    [HACCP API]
                               
1-1-1-2 (전체 업체 수)          인증업체 API (41,083건)
1-2-1-2 (생산액/생산량)              │
1-3-1-1 (위반 건수)                  │ businessitem
1-4-3   (부적합률)                   ▼
     │                         품목코드 API
     │                              │ pcd
     │                              ▼
     │                         pcd → 품목유형 변환
     │                              │
     └──── 품목유형명 ◄──────────────┘
                │
                ▼
         통합 테이블 (식품군 × 변수)
                │
                ▼
         스코어링 (Risk·Scale·Vuln·Impact)
```
